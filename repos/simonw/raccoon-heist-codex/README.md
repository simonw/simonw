# Moonlight & Mayhem

Implemented by GPT-5.6 Sol Ultra running in Codex Desktop using [this prompt](https://simonwillison.net/2026/Aug/5/raccoon-heist/#the-fable-5-prompt). See [Moonlight & Mayhem (Raccoon Heist by Codex + GPT-5.6 Sol Ultra)](https://simonwillison.net/2026/Aug/7/moonlight-mayhem/) and [One-shotting a Raccoon Heist game using Claude Fable 5](https://simonwillison.net/2026/Aug/5/raccoon-heist/) for background on this project.

A tiny, mobile-friendly 3D raccoon heist for the browser. Free the crew, dodge the museum's cameras and BroomBot, steal the suspiciously enormous Golden Sardine, and make it back to the getaway dumpster.

## Play the game

[simonw.github.io/raccoon-heist-codex/](https://simonw.github.io/raccoon-heist-codex/)

## Controls

- Desktop: WASD or arrow keys to move, E to interact, Space or Shift to dash, Escape to pause.
- Mobile: left touch stick to move, paw button to interact, lightning button to dash.

No build step is required. Three.js is vendored locally, and the gpt-image-2 material textures are committed with the game.
